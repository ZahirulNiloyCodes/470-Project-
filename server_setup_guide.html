🎓 EduStream — Complete Server Setup & Run Guide

Distributed Collaborative Learning Platform • FastAPI (Python) Backend + Next.js 14 (TypeScript & Tailwind) Frontend + Supabase (PostgreSQL)

Member 1 Modules: FR1 (Study Rooms), FR5 (Shared Pomodoro), FR9 (AI Flashcards), FR13 (Peer Rating System).

1. Clone Repository from Git

# Clone the repository onto your machine
git clone https://github.com/ZahirulNiloyCodes/470-Project-.git

# Navigate into the project root directory
cd 470-Project-

⚡ 1-Click Instant Launch (No Terminal Needed!)

You don't need to type terminal commands! Simply double-click the launcher script in Windows File Explorer:

  • run.bat (or start.bat): Automatically creates virtual environment, verifies dependencies, starts both FastAPI backend and Next.js frontend, and launches http://localhost:3000/demo in your browser!
  • run_tests.bat: Double-click to execute all 38 backend and 11 frontend unit tests.
  • stop.bat: Double-click to cleanly terminate all background servers when finished.

Note: The app comes with resilient built-in in-memory fallback stores and sample rooms & ratings, meaning it works 100% offline out-of-the-box even without Supabase credentials.

2. Database Initialization (Optional - For Live Supabase Cloud Sync)

Open your Supabase Project Dashboard → SQL Editor → New Query, paste the following SQL, and click Run:

create extension if not exists "uuid-ossp";

-- FR1: Study Rooms
create table if not exists public.study_rooms (
    id uuid primary key default uuid_generate_v4(),
    title varchar(255) not null,
    description text,
    is_private boolean default false,
    access_code varchar(32) null,
    tags text[] default '{}',
    host_id uuid not null default '11111111-1111-4111-a111-111111111111'::uuid,
    max_participants int default 10,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- FR9: Flashcard Decks
create table if not exists public.flashcard_decks (
    id uuid primary key default uuid_generate_v4(),
    room_id uuid references public.study_rooms(id) on delete set null,
    user_id uuid not null default '11111111-1111-4111-a111-111111111111'::uuid,
    title varchar(255) not null,
    cards jsonb not null default '[]'::jsonb,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- FR13: Peer Ratings
create table if not exists public.peer_ratings (
    id uuid primary key default uuid_generate_v4(),
    room_id text not null,
    rater_id text not null,
    ratee_id text not null,
    rating int not null check (rating >= 1 and rating <= 5),
    feedback text,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    updated_at timestamp with time zone default timezone('utc'::text, now()) not null,
    constraint no_self_rating check (rater_id != ratee_id),
    constraint unique_rater_ratee_room unique (room_id, rater_id, ratee_id)
);

-- Enable Row Level Security (RLS) & Policies
alter table public.study_rooms enable row level security;
alter table public.flashcard_decks enable row level security;
alter table public.peer_ratings enable row level security;
create policy "Allow all study_rooms" on public.study_rooms for all using (true) with check (true);
create policy "Allow all flashcard_decks" on public.flashcard_decks for all using (true) with check (true);
create policy "Allow all peer_ratings" on public.peer_ratings for all using (true) with check (true);

3. Backend Setup & Run (Terminal 1)

Open your first terminal (PowerShell or Bash) and run:

# 1. Enter the backend directory
cd backend

# 2. Create a Python virtual environment
python -m venv venv

# 3. Activate the virtual environment
# Windows PowerShell:
.\venv\Scripts\Activate.ps1
# (Or on macOS/Linux/Git Bash: source venv/bin/activate)

# 4. Create your .env configuration file
# Ensure you set your Supabase URL & Anon Key, and OpenAI API Key
# Example backend/.env:
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your_supabase_anon_key
OPENAI_API_KEY=your_openai_api_key
PORT=8000
FRONTEND_URL=http://localhost:3000

# 5. Install all backend dependencies
pip install --upgrade pip
pip install -r requirements.txt

# 6. Launch the FastAPI server
python -m uvicorn main:app --reload --port 8000

Verification: Open http://localhost:8000/docs in your browser to view the interactive FastAPI Swagger UI.

4. Frontend Setup & Run (Terminal 2)

Open a second terminal window and run:

# 1. Enter the frontend directory
cd frontend

# 2. Create your .env.local configuration file
# Example frontend/.env.local:
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000

# 3. Install frontend npm packages
# Note on Windows: Use npm.cmd if PowerShell scripts are restricted
npm install

# 4. Launch the Next.js development server
npm run dev

Verification: Open http://localhost:3000/demo in your browser to view the integrated Member 1 testbed.

5. Running Unit & Integration Tests (Member 1)

All Member 1 unit and integration tests are organized inside dedicated member_1 test directories:
