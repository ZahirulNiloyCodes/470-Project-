🎓 EduStream — Complete Server Setup & Run Guide

Distributed Collaborative Learning Platform • FastAPI (Python) Backend + Next.js 14 (TypeScript & Tailwind) Frontend + Supabase (PostgreSQL)

Member 1 Modules: FR1 (Study Rooms), FR5 (Shared Pomodoro), FR9 (AI Flashcards), FR13 (Peer Rating System).

1. Clone Repository from Git

# Clone the repository onto your machine
git clone https://github.com/ZahirulNiloyCodes/470-Project-.git

# Navigate into the project root directory
cd 470-Project-

⚡ 1-Click Instant Launch (No Terminal Needed!)

You don't need to type terminal commands! Simply double-click the launcher script in Windows File Explorer:

  • run.bat (or start.bat): Automatically creates virtual environment, verifies dependencies, starts both FastAPI backend and Next.js frontend, and launches http://localhost:3000/demo in your browser!
  • run_tests.bat: Double-click to execute all 38 backend and 11 frontend unit tests.
  • stop.bat: Double-click to cleanly terminate all background servers when finished.

Note: The app comes with resilient built-in in-memory fallback stores and sample rooms & ratings, meaning it works 100% offline out-of-the-box even without Supabase credentials.

2. Database Initialization (Optional - For Live Supabase Cloud Sync)

Open your Supabase Project Dashboard → SQL Editor → New Query, paste the following SQL (from backend/schema.sql), and click Run:

CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- FR1: Study Rooms
CREATE TABLE IF NOT EXISTS public.study_rooms (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title VARCHAR(255) NOT NULL,
    description TEXT,
    is_private BOOLEAN DEFAULT FALSE,
    access_code VARCHAR(32) NULL,
    tags TEXT[] DEFAULT '{}',
    host_id UUID NOT NULL DEFAULT '11111111-1111-4111-a111-111111111111'::uuid,
    max_participants INT DEFAULT 10,
    created_at TIMESTAMPTZ DEFAULT NOW() NOT NULL
);

-- FR9: Flashcard Decks
CREATE TABLE IF NOT EXISTS public.flashcard_decks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    room_id UUID REFERENCES public.study_rooms(id) ON DELETE SET NULL,
    user_id UUID NOT NULL DEFAULT '11111111-1111-4111-a111-111111111111'::uuid,
    title VARCHAR(255) NOT NULL,
    cards JSONB NOT NULL DEFAULT '[]'::jsonb,
    created_at TIMESTAMPTZ DEFAULT NOW() NOT NULL
);

-- FR13: Peer Ratings
CREATE TABLE IF NOT EXISTS public.peer_ratings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    room_id TEXT NOT NULL,
    rater_id TEXT NOT NULL,
    ratee_id TEXT NOT NULL,
    rating INT NOT NULL CHECK (rating >= 1 AND rating <= 5),
    feedback TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW() NOT NULL,
    updated_at TIMESTAMPTZ DEFAULT NOW() NOT NULL,
    CONSTRAINT unique_room_rater_ratee UNIQUE (room_id, rater_id, ratee_id)
);

-- Member 2: Whiteboard Canvas, Chat, Q&A, Screen Sharing
CREATE TABLE IF NOT EXISTS public.canvas_records (
    id TEXT PRIMARY KEY, room_id TEXT NOT NULL, record_id TEXT NOT NULL, record_data JSONB NOT NULL, updated_at TIMESTAMPTZ DEFAULT NOW(), CONSTRAINT unique_room_record UNIQUE (room_id, record_id)
);
CREATE TABLE IF NOT EXISTS public.chat_messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(), room_id TEXT NOT NULL, user_id TEXT NOT NULL, username TEXT NOT NULL, content TEXT NOT NULL, is_edited BOOLEAN DEFAULT FALSE, is_deleted BOOLEAN DEFAULT FALSE, created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE TABLE IF NOT EXISTS public.anonymous_questions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(), room_id TEXT NOT NULL, participant_id TEXT, question TEXT NOT NULL, status TEXT DEFAULT 'pending', answer TEXT, answered_at TIMESTAMPTZ, dismissed_at TIMESTAMPTZ, created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE TABLE IF NOT EXISTS public.screenshare_sessions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(), room_id TEXT NOT NULL, participant_id TEXT NOT NULL, participant_name TEXT NOT NULL, is_sharing BOOLEAN DEFAULT TRUE, started_at TIMESTAMPTZ DEFAULT NOW(), ended_at TIMESTAMPTZ
);

-- Member 3: Tasks, Study Logs, Resources
CREATE TABLE IF NOT EXISTS public.room_tasks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(), room_id TEXT NOT NULL, title TEXT NOT NULL, status TEXT DEFAULT 'todo', created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE TABLE IF NOT EXISTS public.study_logs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(), user_id TEXT NOT NULL, duration INT NOT NULL, session_date DATE NOT NULL, notes TEXT, created_at TIMESTAMPTZ DEFAULT NOW()

CREATE TABLE IF NOT EXISTS public.room_resources (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(), room_id TEXT NOT NULL, user_id TEXT NOT NULL, title TEXT NOT NULL, resource_type TEXT NOT NULL, url TEXT NOT NULL, created_at TIMESTAMPTZ DEFAULT NOW()

3. Backend Setup & Run (Terminal 1)

Choose the instructions matching your terminal / operating system:

Option A: Windows Git Bash (MINGW64) — Recommended for Git Bash Users

Note for Git Bash on Windows: Virtual environments on Windows use venv/Scripts/activate (with forward slashes), NOT venv/bin/activate! 
# 1. Enter the backend folder
cd backend

# 2. Copy the .env configuration file
cp .env.example .env

# 3. Create virtual environment
python -m venv venv

# 4. Activate virtual environment (Notice: forward slash and "Scripts")
source venv/Scripts/activate

# 5. Install backend dependencies
pip install --upgrade pip
pip install -r requirements.txt

# 6. Launch FastAPI backend server
python -m uvicorn main:app --reload --port 8000

Option B: Windows PowerShell

Note for PowerShell: If PowerShell script execution is restricted (Execution_Policies error), you do not need to activate; simply run Python directly via .\venv\Scripts\python.exe! 
# 1. Enter the backend folder
cd backend

# 2. Copy the .env configuration file
Copy-Item .env.example .env

# 3. Create virtual environment
python -m venv venv

# 4. Install backend dependencies
.\venv\Scripts\pip.exe install -r requirements.txt

# 5. Launch FastAPI backend server
.\venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000

Option C: macOS / Linux

cd backend
cp .env.example .env
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m uvicorn main:app --reload --port 8000

Verification: Open http://localhost:8000/docs in your browser to view the interactive FastAPI Swagger UI with all 19 endpoints!

4. Frontend Setup & Run (Terminal 2)

Open a second terminal window for the Next.js frontend:

Option A: Windows Git Bash

# 1. Enter frontend directory
cd frontend

# 2. Create .env.local configuration file
cp .env.example .env.local 2>/dev/null || echo "NEXT_PUBLIC_API_URL=http://localhost:8000" > .env.local

# 3. Install packages
npm install

# 4. Run development server
npm run dev

Option B: Windows PowerShell

# 1. Enter frontend directory
cd frontend

# 2. Create .env.local configuration file
if (-not (Test-Path .env.local)) { Set-Content -Path .env.local -Value "NEXT_PUBLIC_API_URL=http://localhost:8000" }

# 3. Install packages (use npm.cmd if PowerShell blocks npm.ps1)
npm.cmd install

# 4. Run development server
npm.cmd run dev

Option C: macOS / Linux

cd frontend
echo "NEXT_PUBLIC_API_URL=http://localhost:8000" > .env.local
npm install
npm run dev

Verification: Open http://localhost:3000/demo in your browser to access the Member 1 Workspace & Unified Room view!
